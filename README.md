# Sprinkles

Sprinkles is a CLI scaffolding tool for Spring Boot applications, allowing developers to generate and configure new projects directly from the terminal.

I created Sprinkles to simplify the initial setup of Spring Boot applications and provide a way to organize projects from the beginning without manually creating their structure.

The tool uses Spring Initializr to generate projects based on the selected configuration, with additional options for project architecture.

## Features

- Interactive project configuration through the terminal.
- Support for Maven and Gradle.
- Selection of Java and Spring Boot versions.
- Dependency selection.
- Custom project metadata and package names.
- Support for JAR and WAR packaging.
- Standard and layered project architectures.
- Automatic generation of a sample REST controller and its test when using layered architecture with Spring Web.

## Installation

Sprinkles can be executed directly using npx or installed globally with npm.

### Using npx

Run Sprinkles without installing it globally:

```bash
npx sprinkles-cli my-api
```

### Global Installation

Install Sprinkles globally:

```bash
npm install -g sprinkles-cli
```

Once installed, generate a project using:

```bash
sprinkles my-api
```

Replace `my-api` with your preferred project name.

## Project Architecture

Sprinkles supports two project structures.

### Standard

Uses the default project structure generated by Spring Initializr without additional modifications.

### Layered

Organizes the project into separate packages based on their responsibilities:

```text
src/
├── main/
│   └── java/
│       └── com/example/myapi/
│           ├── controller/
│           ├── service/
│           ├── repository/
│           ├── entity/
│           ├── dto/
│           ├── config/
│           └── exception/
└── test/
    └── java/
        └── com/example/myapi/
            ├── controller/
            ├── service/
            └── repository/
```

When Spring Web is selected, Sprinkles also generates a `HelloController` with a `/hello` endpoint and an accompanying test.

## Running the Generated Project

After generating a project, navigate to its directory:

```bash
cd my-api
```

For Gradle projects:

```bash
./gradlew bootRun
```

For Maven projects:

```bash
./mvnw spring-boot:run
```

A compatible Java JDK is required to run the generated application.

On Linux or macOS, you may need to grant execution permissions to the Gradle or Maven wrapper using `chmod +x`.

## Development

To run Sprinkles locally:

```bash
git clone https://github.com/messeyes/Sprinkles.git
cd Sprinkles
npm install
npm run build
```

Link the CLI locally:

```bash
npm link
```

You can now execute:

```bash
sprinkles my-api
```

Run the automated tests with:

```bash
npm test
```
